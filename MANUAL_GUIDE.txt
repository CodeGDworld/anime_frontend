----------------------------------------------------------------------------------------------------
4.1 Core HTML Entrypoint (index.html)
----------------------------------------------------------------------------------------------------
File: index.html
Lines: 308 lines
Role: Master Single Page Application container. Contains static navigational scaffolding and 
      anchors where dynamic JavaScript views inject content.

Key DOM Elements & Controlled Surfaces:
- `<div id="manga-transition-canvas">`: Target for WebGL GLSL Halftone Ink dissolve shaders.
- `<header class="app-header">`: Sticky navigation bar containing:
    * Dropdown Menus: Genres (4), Seasons (4), Demographics (5), Attacks Dojo (6).
    * `<div class="search-wrapper">`:
        - `#global-search-input`: Text input for live instant search.
        - `#voice-search-btn`: Microphone icon button (🎙️) powering voice recognition.
        - `#search-results-dropdown`: Pop-up results container with live thumbnails.
    * `#nav-arena-btn`: Launches the 3D Video Hologram Arena.
    * `#audio-toggle-btn`: Toggles Web Audio procedural sound matrix (ON/OFF).
    * `#header-user-slot`: Dynamically populated by js/auth-ui.js with User/Admin badge.
- `<main id="app-content">`: Master dynamic viewport where js/router.js injects Home, Category,
  ML Studio, Favorites, Admin, and Profile views without refreshing the browser.
- `<div id="anime-detail-modal">`: Popup dialog displaying full anime information, synopsis,
  ratings, ML score, and attack triggers.
- `<script type="module" src="js/app.js">`: Bootstraps ES module loading.

4.2 Styling Layer (css/*.css)
----------------------------------------------------------------------------------------------------

1. css/main.css
   Surface: Global layout, typography, header, search bar, and anime detail modal.
   Features:
   - Modern dark slate foundation with CSS custom properties (`--bg-primary`, `--accent-cyan`).
   - `.search-wrapper` and `.voice-search-btn`: Absolute positioning for microphone inside search.
   - `.voice-search-btn.listening`: Keyframe red-pulse animation when microphone is active.
   - `.search-input.voice-active`: Red glow border while user speaks into microphone.
   - Modal backdrop, responsive breakpoints, and glassmorphism styling.

2. css/category-themes.css
   Surface: Entire page background dynamically adapting per category.
   Features:
   - Injects custom CSS classes onto the `<body>` element when routing between categories:
     * `.theme-slice-of-life`: Pastel sakura rose (#f43f5e) and gentle floral glow.
     * `.theme-mystery`: Obsidian violet and noir purple shadow matrix.
     * `.theme-action`: Volcanic crimson (#ef4444) and ember fire accents.
     * `.theme-romance`: Radiant magenta (#ec4899) and warm starlight.
     * `.theme-winter`: Glacial cyan (#38bdf8) and sub-zero frost shimmer.
     * `.theme-spring`: Emerald sprout (#10b981) and fresh spring breeze.
     * `.theme-summer`: Solar amber (#f59e0b) and midday heat haze.
     * `.theme-autumn`: Maple bronze (#d97706) and golden twilight.
     * `.theme-shounen` / `.theme-seinen` / etc.: Demographic battle palettes.
     * `.theme-home`: Balanced eye-friendly midnight slate and indigo starlight.

3. css/cube.css
   Surface: 3D Category Cube and 3D Cylindrical Poster Carousel.
   Features:
   - Uses CSS 3D Transforms (`transform-style: preserve-3d`, `perspective: 1200px`).
   - `.cube-3d`: 6-sided 3D cube with faces rotated along X and Y axes (`rotateY(0deg)`,
     `rotateY(90deg)`, `rotateY(180deg)`, `rotateY(-90deg)`, `rotateX(90deg)`, `rotateX(-90deg)`).
   - `.cube-orbit-ring`: Circular gyroscope dial with neon sweep border for rotating categories.
   - `.carousel-3d-stage`: Cylindrical ring displaying 10 anime posters distributed evenly across 
     360 degrees (`rotateY(calc(var(--index) * 36deg)) translateZ(380px)`).

4. css/saitama.css
   Surface: Floating Saitama HelpBot widget in bottom-right corner.
   Features:
   - `.saitama-aura-wrapper`: Circular avatar badge with radiant golden-yellow aura halo glow
     (`box-shadow: 0 0 25px #facc15, 0 0 50px rgba(234, 179, 8, 0.65)`).
   - `.saitama-card`: High-contrast pure white speech card with rounded corners (`border-radius: 20px`).
   - `.chip-action` & `.chip-sol`: Solid black pill buttons with neon cyan border (`#00f0ff`).
   - `.chip-punch`: Solid vibrant magenta pill button (`#ff2a85`).
   - `.saitama-mic-btn.listening`: Expanding red ripple wave when HelpBot listens to speech.

5. css/cards.css
   Surface: Catalog grid of anime cards.
   Features:
   - 3D hover tilt perspective with mouse movement.
   - Holographic foil shimmer on high-tier ratings (⭐ 8.5+).
   - Studio badge, release year pill, signature move tag, and ML hit probability pill.

6. css/signature-moves.css
   Surface: Full-screen visual effects for anime attack moves.
   Features:
   - Fullscreen fixed canvas container with z-index: 5000.
   - Screen shake animations (`@keyframes screen-quake`).
   - Manga speedlines, radial blast waves, and Japanese Kanji banner typography.

7. css/ml.css
   Surface: Logistic Regression ML Studio page (`#ml-studio`).
   Features:
   - Interactive SVG Sigmoid curve coordinate grid (`z = w·x + b`).
   - Dynamic decision boundary marker and interactive feature weight sliders.

8. css/admin.css, css/auth.css, css/favorites.css
   Surfaces: Admin command center table, Login/Register modal, and Favorites Vault.

4.3 Client-Side Logic & Dynamic UI Layer (js/*.js)
----------------------------------------------------------------------------------------------------

1. js/app.js
   Role: Master Application Bootstrapper.
   Connections:
   - Imports and initializes `mangaTransition` (WebGL canvas).
   - Initializes `video3DShaderPipeline` (hidden HTML5 video tags).
   - Initializes `movesEngine` and `video3DTheater`.
   - Initializes `AppRouter` and binds hash changes.
   - Initializes `AuthAndPanelsUI` and checks active JWT session.
   - Initializes `SaitamaAssistant` (HelpBot).

2. js/router.js
   Role: Dynamic Single-Page Application (SPA) Router & View Builder.
   Methods & Surfaces:
   - `renderHome()`: Injects Hero section, 3D Category Cube, and Top 10 Trending Anime.
   - `renderCategory(categoryId)`: Updates category background theme, renders 3D Poster 
     Carousel or Grid view, and displays 10 curated category anime.
   - `renderMLStudio()`: Renders interactive Sigmoid S-curve and feature weight simulator.
   - `renderFavorites()`: Renders user's personal favorites vault.
   - `renderAdmin()`: Renders admin management portal with CRUD table for 130 anime.
   - `setupSearch()`: Attaches live text filtering and binds `#voice-search-btn` to `voiceRecognition`.
   - `openAnimeModal(id)`: Builds and displays full 3D detail modal for any anime.

3. js/speech.js
   Role: Speech-to-Text Voice Recognition Engine (Web Speech API).
   Classes & Methods:
   - `VoiceRecognitionEngine`:
     * `startSearchListening(inputEl, callback)`: Listens to user voice, streams interim 
       transcription into `#global-search-input`, and fires live search filtering.
     * `startHelpBotListening(inputEl, callback)`: Streams spoken words into Saitama HelpBot.
     * `fallbackSimulation()`: If browser microphone permission is blocked, automatically 
       executes an animated typing simulation with sample anime voice queries so it never fails.

4. js/saitama.js
   Role: Interactive Saitama HelpBot & AI Concierge.
   Surfaces & Interactions:
   - Renders the circular Saitama SVG avatar badge matching the user's reference image.
   - Renders the white speech card with action chips:
     * `🔥 HYPE ACTION` -> Recommends high-energy action anime (*Solo Leveling*, *Attack on Titan*).
     * `🌸 CHILL SLICE OF LIFE` -> Recommends soothing anime (*Frieren*, *Bocchi the Rock!*).
     * `🥊 ONE PUNCH PICK` -> Calculates top ML hit (*Vinland Saga*) and unleashes Serious Punch!
   - Natural Language Intent Engine (`handleUserQuery`):
     * Parses queries like "Recommend romance", "Winter anime", "Explain ML", "Serious Punch",
       "Take me to favorites", or anime names like "Chainsaw Man".
     * Embeds mini anime poster cards inside chat with 1-click "VIEW" modal launcher.
   - Voice Integration: Mic button triggers `voiceRecognition.startHelpBotListening()`.

5. js/cube-nav.js
   Role: 3D Category Cube Navigation & Cylindrical Poster Carousel.
   Classes:
   - `Category3DCube`: Handles mouse drag, touch swipe, and circular gyroscope dial rotation. 
     Calculates 3D orientation (`currentRotX`, `currentRotY`) and navigates to target category.
   - `Anime3DCarousel`: Arranges 10 anime posters in a 3D cylindrical ring with smooth rotation.

6. js/moves.js
   Role: Signature Attacks Canvas Engine.
   Moves Implemented:
   - `kamehameha`: Cyan charging orb + full-width plasma beam + blue particle vortex.
   - `serious_punch`: Saitama death blow, screen shatter fracture lines, shockwave distortion.
   - `domain_expansion`: Dark infinite void, celestial halo rings, floating eye kanji.
   - `sakura_blossom`: Swirling pink cherry blossom petals, gentle wind swirl.
   - `ice_glaciation`: Sub-zero frost spikes spreading across screen, ice crystals.
   - `solar_flare`: Blinding white-gold flash, radial lens flare, fading afterglow.

7. js/audio.js
   Role: Web Audio API Procedural Sound Matrix.
   Synthesizes authentic procedural anime sound effects without external audio files:
   - Energy beam whoosh, sonic boom explosion, ink splatters, halftone pops, and cube clacks.

8. js/manga-transition.js
   Role: WebGL Dynamic "Manga Ink" Transition Shaders.
   Shaders:
   - Custom GLSL vertex and fragment shader.
   - Page cuts dissolve into monochrome Halftone screentone dots and Sumi-e ink splatters.

9. js/video-shader-pipeline.js & js/video-theater.js
   Role: Video-to-3D Shader Pipeline (WebCodecs & WebGL / Three.js).
   Architecture:
   - Hidden HTML5 `<video autoplay muted loop playsinline style="display:none">` tags.
   - Feeds `THREE.VideoTexture` bound to emissive curved meshes and particle billboard clouds.

10. js/data.js & js/poster-fallback.js
    Role: Master dataset with 130 curated anime entries across 13 categories with authentic posters, 
    studios, ratings, and feature statistics; plus SVG vector fallback generator.

11. js/api.js & js/auth-ui.js
    Role: Unified client API layer communicating with Node.js backend with automatic localStorage 
    fallback, managing user authentication and modal interfaces.

----------------------------------------------------------------------------------------------------
4.4 Backend Server, Storage & Machine Learning (server/*.js, database.json)
----------------------------------------------------------------------------------------------------

1. server/index.js
   Role: Zero-dependency Node.js HTTP REST API Server.
   Port: 3000 (auto-increments on collision e.g. 3001).
   Endpoints:
   - `GET  /api/health`: Health status and ML model state.
   - `POST /api/auth/register`: User registration with SHA-256 password hashing.
   - `POST /api/auth/login`: User authentication returning JWT session token.
   - `GET  /api/anime`: Retrieves catalog of 130 anime.
   - `POST /api/favorites/toggle`: Synchronizes user favorites list.
   - `POST /api/ml/predict`: Runs real-time popularity prediction on any anime.
   - `GET  /api/admin/stats`: Master admin statistics (total users, anime, favorites).

2. server/ml.js
   Role: In-memory Logistic Regression Machine Learning Engine.
   Mathematical Formulation:
   - Linear combination:
     z = w1*Rating + w2*Members + w3*Favorites + w4*StudioPrestige + w5*Year + bias
   - Sigmoid Activation Function:
     P(Hit = 1) = 1 / (1 + e^-z)
   - Features Normalized via Z-Score: (x - mean) / std_deviation.
   - Trained via Gradient Descent with binary cross-entropy loss over 130 anime.

3. server/db.js & server/data/database.json
   Role: File-based persistence engine using atomic writes.
   Stores 130 anime records, user accounts, and favorites lists safely without corrupting data.
